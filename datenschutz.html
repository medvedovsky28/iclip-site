Datenschutzerklärung

Stand: 11. November 2026

Wer iClip nutzt

iClip ist ein privates Werkzeug. Es wird nur vom Betreiber genutzt, um Kurzvideos auf seinen eigenen Kanälen zu veröffentlichen. Andere Personen können sich nicht anmelden.

Welche Daten verarbeitet werden

  • Beim Verbinden eines eigenen Kanals (YouTube über Google, Instagram über Meta, TikTok über den Dienst Zernio) erhält iClip einen Zugangsschlüssel (Token). Damit lädt iClip Videos auf diesen Kanal hoch und liest die Statistiken der eigenen Videos (zum Beispiel Aufrufe und Wiedergabedauer).
  • Gespeichert werden der Zugangsschlüssel (verschlüsselt), der Name und die Kennung des Kanals sowie die Statistiken der eigenen Videos.
  • Die Daten liegen verschlüsselt in einer Datenbank von Supabase in der EU (Frankfurt).

Was nicht passiert

  • Keine Weitergabe oder kein Verkauf von Daten an Dritte.
  • Keine Werbung, kein Tracking, keine Cookies auf dieser Website.
  • Kein Zugriff auf Daten anderer Personen.

Google und YouTube

iClip nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google. Der Zugriff von iClip lässt sich jederzeit in den Google-Kontoeinstellungen widerrufen.

Die Nutzung von Daten, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Löschen

Wird ein Kanal in iClip getrennt, wird sein Zugangsschlüssel gelöscht. Statistiken fremder Kanäle (nur zum Vergleich) werden höchstens 30 Tage gespeichert.
